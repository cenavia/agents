# agent-config — Claude Code Plugin

> Scaffolds and manages the full **agent/sub-agent configuration layer** for any project,
> following the [agentskills.io](https://agentskills.io) open standard.

---

## What This Plugin Does

This plugin generates everything needed to run a multi-agent AI development workflow:

| Component | What it generates |
|-----------|------------------|
| `AGENTS.md` | Per-scope AI agent rulesets with Auto-invoke tables |
| `skills/` | Skill stubs with correct frontmatter + sync tooling |
| `setup.sh` | Multi-AI-assistant configurator (Claude, Codex, Gemini, Copilot) |
| `sync.sh` | Auto-syncs skill metadata → AGENTS.md Auto-invoke sections |
| Templates | Reusable `AGENTS.md`, `SKILL.md`, and agent `.md` templates |

---

## Quick Start

```bash
# Load the plugin
claude --plugin-dir ./agent-config-plugin

# Scaffold a new project
/agent-config:agent-scaffold

# Create a new skill
/agent-config:skill-designer django-migrations --scope api

# Sync AGENTS.md after skill changes
/agent-config:agents-sync
```

| Skill | Trigger | What it does |
|-------|---------|-------------|
| `agent-scaffold` | Setting up agent config | Generates full project agent structure |
| `skill-designer` | Creating a new skill | Designs SKILL.md with correct metadata |
| `agents-sync` | After modifying skills | Syncs Auto-invoke tables in AGENTS.md |

## Blueprint §5 — Estructura generada

```
/
├── AGENTS.md              ← fuente de verdad — editar aquí
├── .claude.md             ← symlink → AGENTS.md  (Claude Code lo lee)
├── api/
│   ├── AGENTS.md          ← reglas Django 5.1 / PostgreSQL 16
│   └── .claude.md         ← symlink → api/AGENTS.md
├── ui/
│   ├── AGENTS.md          ← reglas Next.js 16 / React 19
│   └── .claude.md         ← symlink → ui/AGENTS.md
└── skills/
    ├── setup.sh           ← despliega symlinks para todos los asistentes
    ├── skill-sync/
    │   └── assets/sync.sh ← sincroniza metadata → tablas AGENTS.md
    └── {skill-name}/
        └── SKILL.md
```

> `.claude.md` es **siempre un symlink**, nunca una copia.
> Editar `AGENTS.md` se propaga automáticamente a Claude Code.

The plugin implements the **Prowler pattern** — the reference implementation of
agentskills.io used in production at [prowler-cloud/prowler](https://github.com/prowler-cloud/prowler).

```
skills/*/SKILL.md          ← source of truth
    metadata.scope         → which AGENTS.md to update
    metadata.auto_invoke   → action rows in the Auto-invoke table
         ↓
AGENTS.md ### Auto-invoke Skills  ← auto-generated by sync.sh
```

AI assistants **don't reliably auto-invoke skills** just from the description.
The Auto-invoke sections in AGENTS.md explicitly command the AI:
*"When performing X, ALWAYS invoke Y skill FIRST."*

## Multi-AI-Assistant Support

After scaffolding, run `./skills/setup.sh` to configure:

| Tool | Symlink created |
|------|----------------|
| Claude Code | `.claude/skills/` → `skills/` |
| Codex (OpenAI) | `.codex/skills/` → `skills/` |
| Gemini CLI | `.gemini/skills/` → `skills/` |
| GitHub Copilot | `.github/copilot-instructions.md` |

## Estructura del plugin (estándar Claude Code)

```
agent-config-plugin/
├── .claude-plugin/
│   └── plugin.json              ← SOLO el manifest (regla del estándar)
├── skills/
│   ├── agent-scaffold/
│   │   ├── SKILL.md             ← instrucciones de scaffolding
│   │   ├── assets/              ← scripts desplegados en proyectos del usuario
│   │   │   ├── setup.sh         ← configura Claude/Codex/Gemini/Copilot
│   │   │   ├── sync.sh          ← sincroniza AGENTS.md desde SKILL.md
│   │   │   └── scaffold.sh      ← genera estructura completa
│   │   └── templates/           ← plantillas usadas al generar contenido
│   │       ├── AGENTS.md.tpl
│   │       ├── SKILL.md.tpl
│   │       └── agent.md.tpl
│   ├── skill-designer/
│   │   └── SKILL.md
│   └── agents-sync/
│       └── SKILL.md
├── agents/
│   ├── orchestrator.md
│   ├── agents-configurator.md
│   └── skill-designer.md
├── hooks/
│   └── hooks.json               ← usa ${CLAUDE_PLUGIN_ROOT}/scripts/
```
